# TASK5：机器学习分类与模型评价

本任务使用 scikit-learn 乳腺癌诊断数据，完成从数据检查、标签重编码、分层划分和训练集内特征选择，到四种模型训练、概率预测、ROC-AUC评价和模型解释的完整流程。

## 结论先行

569例患者样本被分为455例训练样本和114例测试样本。恶性统一编码为1。特征筛选只读取训练集，最终保留6项变量。

逻辑回归和随机森林的测试ROC-AUC都约为 **0.994**，梯度提升约为 **0.992**，决策树约为 **0.972**。前三种模型的区间高度重叠，不能按千分位差别确定稳定排名。0.5阈值下，决策树的Balanced Accuracy和恶性召回率最高，梯度提升的F1和Brier更好。

高AUC主要说明当前细胞核形态特征与诊断之间存在较强的可分关系，不代表算法在其他场景也会得到同样结果。本任务是教学数据上的内部测试，不用于医学诊断。

## 关于交易数据预测

报告结尾保留了此前使用交易数据进行机器学习预测的结果。三种口径的最高样本外AUC分别为0.533、0.529和0.524，置信区间均覆盖0.5。日期边界、标签复算、Mann-Whitney秩公式、随机标签和人工可预测标签测试没有发现机械错误。

失败结果的讨论进一步比较了验证期和测试期。60日截面排名中，逻辑回归AUC由2023年的0.752降至2024年的0.575和2025年的0.509，随机森林也由0.726降至0.594和0.533。报告据此讨论市场状态变化、价量因子的信息同源、20日和60日标签重叠、有效时间状态不足，以及目标与交易决策不完全一致的问题。不同金融口径之间不直接排名，也不把0.52修饰为有效信号。

## 阅读边界

- 患者样本按独立观察处理，分层随机划分不适用于金融时间序列。
- 系数和树模型重要性解释模型依赖，不表示医学因果。
- 教学数据没有外部医院、设备或人群验证。
- 本项目仅用于课程学习和模型流程演示。
