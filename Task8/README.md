# Task 8 - Portfolio Synthesis

Task 8 synthesizes the preceding work as one research pipeline:

```text
market data -> indicators -> rule-based backtests ->
supervised learning -> portfolio construction -> monitoring
```

## Main conclusions

- Data contracts and time boundaries determine whether later calculations are valid.
- Rule transparency makes simple strategies useful baselines even when returns are weak.
- Machine-learning results depend on label design, leakage controls, temporal stability, costs, and portfolio construction.
- Backtests, platform simulations, and public-data shadow portfolios answer different questions and must remain separately labeled.
- Reproducibility depends on committed inputs, deterministic settings, structured outputs, and metric checks.
