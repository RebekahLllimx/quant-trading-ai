# TASK8 专业学习报告实施规格（已确认）

> 报告暂定题目：**《从数据到执行：量化交易策略与机器学习应用的综合实践报告》**

## 一、任务定位

TASK8只提交专业学习报告，不制作策略路演、演示文稿或演讲稿。报告综合TASK1—TASK7的学习内容，以课程任务书为硬性要求，并参考`Task8/references/course/`课程PPT的一般量化报告写法，形成一份能够独立阅读、结论有证据、限制可追溯的技术型总结报告。

报告同时强调个人思考，但个人思考不单独替代技术分析。每项重要反思都要从前期作业中的数据、图表、失败结果或方法选择出发，说明“我如何理解这项结果、它改变了什么认识、下一步会怎样处理”，避免只写感想、口号或泛化的学习体会。

本报告不追求把每项作业包装成成功策略，而是展示以下完整研究链条：

> 数据获取与质量控制 → 指标和特征构建 → 规则策略回测 → 机器学习建模 → 交易决策与风险控制 → 执行验证 → 复盘改进

报告的主线结论暂定为：

1. TASK1—TASK6已经形成从数据、指标、策略到机器学习评价的基本量化研究框架。
2. TASK3和TASK4在相同下跌样本中降低了相对买入持有的损失和回撤，但绝对收益仍为负，现有结果只支持风险控制和方法学习，不支持稳定盈利结论。
3. TASK5说明规范的数据划分、特征筛选和模型评价比单一高分更重要；医疗教学数据上的高AUC不能外推到金融市场，金融数据上的弱预测结果同样具有学习价值。
4. TASK6显示机器学习可以形成一定的横截面排序信息，但测试期只有3个季度；同时，方向预测指标的改善没有自动转化为更高交易收益。
5. TASK7已经形成正式报告、三策略长期平台回测、扩展样本本地复算、成本压力测试和五日冻结参数回放；三个私有模拟盘已部署但尚无运行数据。因此可以报告“从回测到部署”的方法与历史证据，不能报告模拟盘或真实资金绩效。
6. 综合学习成果的核心不是“找到印钞策略”，而是建立系统思维、数据思维、风险意识和可复核的实践方法。
7. 个人认识的变化应由技术证据推动：从关注策略收益逐步转向数据质量、有效样本、样本外稳定性、风险预算、执行约束和持续监控。

### 2.4 Jump Trading课件的使用边界

`Task7/reference/jump trading/`中的五页课件可作为专业观点和个人反思的触发材料，但不属于TASK7交易结果，也不能替代本项目数据分析。

用户在学校修读《量化金融专题》期间，课程邀请Jump Trading进行客座讲座。听完后，用户认为讲座对低信噪比、有效样本、市场变化和研究系统的经验，与TASK5至TASK7中的实际体验高度吻合。成稿首次引入Jump Trading时必须先交代这一课程背景，再转入观点与个人反思；后文只用“那场客座讲座”等指代承接，避免重复介绍。

可借鉴的五组观点：

1. **预测期限、模型容量和数据量存在三难关系。** 长周期预测难度高、独立样本少；短周期样本更多，但模型推断速度和交易执行更重要。
2. **真正有竞争力的是研究系统，而不只是模型。** 技术能力之外，还包括透明度、可复现工作、清晰文档、自动化、协作和长期迭代。
3. **市场不会静止。** 波动、流动性、投资者行为、监管、市场结构和参与者都会变化，历史信号可能衰减。
4. **人工智能的价值先来自问题和数据设计。** 应先定义可交易目标、控制噪声和泄漏，再考虑更复杂的模型和更大算力。
5. **最关键的问题是“真实信号，还是结构化噪声”。** 更多特征不一定更好，验证、稳健性和时间戳对齐与建模同等重要。

使用规则：

- 课件观点必须与TASK3—TASK6中的实际结果连接后再展开。
- 报告说明“讲座经验与前期任务体验相互呼应”，不能写成“实验已经证明Jump Trading的结论”。
- 不声称用户在Jump Trading拥有工作或实盘经验。
- 若引用课件观点，参考资料中注明课件来源；正文使用中文转述，不直接粘贴英文课件截图。

## 三、写作对象、目标与证据标准

### 3.1 目标读者

目标读者为了解基本金融概念、但未参与前七项任务的课程导师或专业读者。报告采用技术报告深度，但首次出现AUC、IC、最大回撤、滑点等术语时必须用中文解释。

### 3.2 写作目标

读者在阅读后应能够回答：

1. 学员完成了哪些量化研究环节？
2. 各项策略和模型使用了什么数据、假设和评价方法？
3. 哪些结果有明确证据，哪些只是探索性发现？
4. 规则策略和机器学习策略分别适合什么场景？
5. 现有研究的主要风险与限制是什么？
6. 下一步最值得优先改进的内容是什么？

### 3.3 证据等级

| 等级 | 定义 | 写作方式 |
|---|---|---|
| A：可复算结果 | 有结构化数据、冻结口径和可复现输出 | 可报告精确数值，同时说明样本和基准 |
| B：教学性样本结果 | 结果可复算，但样本短、单标的或外部有效性不足 | 可报告数值，必须就近给出限制 |
| C：方法经验 | 教学案例或跨领域示例，不能直接证明金融有效性 | 用于说明流程，不外推盈利能力 |
| D：计划或假设 | 尚未实施的过滤器、参数、部署或改进方案 | 使用“拟”“计划”“有待验证”，不得写成结果 |
| 暂缺 | TASK7尚无模拟盘运行数据 | 不填写模拟绩效，并明确需要哪些后续证据 |

### 3.4 语言边界

- 没有统计显著性检验时，不使用“显著提高”“显著优于”等措辞。
- 单次样本表现较好时写“在本样本中更高/更低”，不写“普遍有效”。
- 跑赢基准但绝对收益为负时，必须同时报告两项事实。
- 参数扫描得到的较优参数写“在候选参数和本样本中表现相对平衡”，不写“经验最优”。
- 模型测试表现高于其他模型，但没有预先选择或独立复验时，不写“最佳模型”。
- 回测、模拟交易、影子跟踪和真实资金交易必须严格区分。

### 3.5 个人思考的写作规则

个人思考采用“证据—判断—变化—行动”四步结构：

1. **证据：** 先说明对应图表、指标、失败案例或方法选择。
2. **判断：** 解释该结果在当前样本中意味着什么、不意味着什么。
3. **变化：** 使用第一人称说明结果如何修正了原有认识。
4. **行动：** 提出以后会怎样改进数据、验证、风控或执行。

建议全文约70%—80%为技术事实、方法和图表分析，约20%—30%为个人解释、认识变化与未来行动。个人反思分散放在相关章节结尾，不单独堆成与前文脱节的“心得体会”。

各任务可形成的个人思考主线：

| 任务 | 技术触发点 | 个人思考方向 |
|---|---|---|
| TASK1 | 数据获取、前复权、自动化管线 | 从“有数据即可分析”转向重视数据版本、口径和可追溯性 |
| TASK2 | 多指标、参数和信息重叠 | 从“指标越多越全面”转向区分信息维度和待检验假设 |
| TASK3 | 简单规则、负绝对收益、缺少风险标准化 | 认识到完成回测闭环比找到一组漂亮参数更重要 |
| TASK4 | ATR止损、仓位预算、连续亏损和执行纪律 | 从关注入场准确率转向关注亏损大小、风险预算和执行约束 |
| TASK5 | 医疗案例高AUC、金融案例接近随机 | 认识到模型不能创造数据中不存在的信息，失败结果也需要验证和解释 |
| TASK6 | 验证高分未延续、预测分数未转化为收益 | 认识到测试集纪律、简单基准和交易目标比调参冠军更重要 |
| TASK7 | 平台回测、本地复算、短窗空仓、模拟盘等待数据 | 从“算法即策略”转向理解版本、数据时点、成本、成交和监控共同构成交易系统 |

以下第一人称内容已经由用户确认，可以进入成稿：

1. **认识起点：** 学习前把量化交易主要理解为算法，接近解决一道数学题；学习后把它理解为在持续信息不对称和信息边界下运行的系统。数据是否完整、特征是否及时、模型是否跨期有效、订单是否成交，都是系统的一部分。
2. **关键触发：** TASK6最触动用户。验证高分没有稳定迁移，滚动逻辑回归测试AUC约0.571但交易收益只有0.50%，低于买入持有9.93%和均线策略9.68%。这使用户直观感受到金融问题的低信噪比，也认识到初学者仅靠调参难以替代金融市场知识、经验和判断。
3. **风险偏好：** 评价目标取决于角色。作为服务金融机构的从业者，会在治理和风险约束内更进取地关注收益，同时重视可解释性，以便审查、沟通和执行；作为个人投资者，更看重稳定性、回撤和能否长期坚持。
4. **对Jump Trading观点的回应：** 用户认同金融市场信噪比很低，并进一步追问：可盈利信号为什么应被当作必然存在，而且为什么应当相信它能被研究者发现？报告将把这一问题写成研究纪律，而非抽象口号——不把信号存在作为先验，每个策略都是可被否证的假设，“尚未发现稳定信号”也是有效结论。
5. **未来方向：** 用户希望继续深入策略研究和机器学习，重点关注深度学习、多模态模型与非结构化数据，并对领域专用化模型有兴趣。报告同时保留方法边界：更丰富的数据和更先进的模型可能扩大可解释信息集，但必须通过时间对齐、简单基准、样本外验证、成本与执行检验，不能预设复杂模型必然发现可盈利信号。

上述观点在成稿中不得原样堆叠为一段感想，而要分别落在TASK6失败分析、TASK7系统部署、综合风险和结论展望中。特别需要保留以下张力：

- **解释的直觉与证据的怀疑并存。** 可以写“我直觉上倾向相信复杂现象可能存在可解释结构”，但不能写“一切都可以被模型解释”。
- **探索深度学习与反对复杂度崇拜并不矛盾。** 研究非结构化数据的理由是扩展信息来源，不是为了用更大的模型掩盖弱标签、泄漏或样本不足。
- **机构与个人的目标函数不同。** 机构场景中的进取收益目标仍受风险预算、解释性和治理约束；个人场景中的稳定性也不等于只持现金或拒绝风险。

## 第一章 研究背景与量化交易核心概念

### 1.1 研究背景与学习目标

说明传统主观交易在信息处理、纪律执行、复盘和规模化方面的局限，引出量化交易通过规则、数据和程序形成可检验决策的特点。避免把量化交易描述成保证盈利的工具。

### 1.2 量化交易的基本概念

用完整流程解释：

> 研究问题 → 数据 → 特征/指标 → 信号 → 仓位 → 交易成本 → 回测 → 样本外验证 → 执行监控

首次解释：

- 回测：用历史数据按预先确定的规则模拟交易。
- 样本外验证：在模型和参数确定后，用未参与选择的数据检验。
- 最大回撤：资产从历史高点到随后低点的最大跌幅。
- 滑点：理论成交价与实际可成交价格之间的偏差。

### 1.3 量化交易的核心价值

从四个维度展开：

1. 规则透明：把交易想法转化为可复核条件。
2. 数据决策：用历史证据检验，而不是只依赖直觉。
3. 风险纪律：提前定义仓位、止损、成本和停用规则。
4. 可迭代性：保留数据、模型和日志，支持复盘与改进。

本章结尾过渡：

> 量化研究能否可靠，首先取决于输入数据和特征定义是否一致，因此下一章从数据基础与指标构建开始。

本章个人思考落点：

> 课程开始时对量化交易的直观认识可能更接近“用程序寻找交易机会”，而前期实践逐步表明，它首先是一套把假设变成可检验规则、把风险和失败记录下来的研究方法。该段最终需要用户补充课程前的真实认识后再定稿。

### 2.2 技术指标与特征分类：TASK2

不逐项重复八个指标的长公式，按交易作用归纳：

| 类别 | 代表指标 | 在系统中的作用 |
|---|---|---|
| 趋势方向 | 移动平均线、指数平滑异同移动平均线 | 描述价格方向和趋势结构 |
| 动量速度 | 相对强弱指标、随机指标 | 描述涨跌速度和短期极端位置 |
| 波动程度 | 平均真实波幅、布林带 | 衡量价格波动和设置风险尺度 |
| 趋势强度/偏离 | 平均趋向指数、商品通道指数 | 辅助识别市场状态和价格偏离 |

关键经验：

- Wilder平滑与普通指数移动平均的权重不同，计算口径必须明确。
- 参数没有跨市场、跨周期的固定最优值。
- 指标阈值是待检验假设，不能仅凭图形观察认定其具有预测能力。
- 多个高度相关的价量指标并不必然带来更多独立信息。

本章结尾过渡：

> 指标只有被转化为明确的入场、退出和仓位规则后才能接受回测检验，TASK3和TASK4据此比较两类趋势跟踪策略。

本章个人思考落点：

- TASK1使数据工作从“下载一份行情”转变为可重复的数据管线，但也暴露出接口变化、复权和历史覆盖需要持续记录。
- TASK2使“指标越多越全面”的直觉受到修正：多个技术指标可能只是对同一价格历史的不同变换，变量数量不能等同于独立信息数量。

## 第三章 规则量化策略综合分析

### 3.1 公平比较口径

核心比较使用相同标的和相同区间：

### 3.2 双均线策略：TASK3

写作重点：

- MA5上穿MA15买入，下穿卖出。

- 绝对收益和夏普比率仍为负，不能称为盈利策略。

### 3.3 海龟策略：TASK4

写作重点：

- 唐奇安通道突破负责入场和退出。
- 平均真实波幅用于止损距离和风险预算。
- 与双均线相比，海龟策略的主要差异是仓位与风险管理，不应简单解释为入场预测更准确。
- 理论风险预算只有在止损可成交、没有跳空或流动性冲击时才近似成立。

冻结结果：

| 指标 | 海龟策略 | 双均线策略 | 买入持有 |
|---|---:|---:|---:|
| 累计收益率 | -0.74% | -5.67% | -18.24% |
| 年化收益率 | -0.47% | -3.61% | -11.63% |
| 最大回撤 | -9.72% | -15.20% | -21.35% |
| 夏普比率 | -0.29 | -0.58 | -1.12 |

- 在本样本中，海龟策略的累计损失和最大回撤均低于双均线。
- 较低回撤与ATR止损、较少交易和风险预算机制一致，但单一样本不能证明因果关系或普遍有效性。

### 3.4 策略适用场景与失效条件

| 市场状态 | 双均线 | 海龟策略 | 共同风险 |
|---|---|---|---|
| 持续上涨趋势 | 可跟随趋势，但入场滞后 | 可通过突破入场并管理风险 | 趋势结束后退出滞后 |
| 区间震荡 | 均线反复交叉 | 假突破后频繁止损 | 成本和小额亏损累积 |
| 单边下跌、仅做多 | 可空仓减少部分损失 | 风险预算可能降低回撤 | 难以形成正收益 |
| 跳空或流动性不足 | 理论成交价偏乐观 | 止损可能无法按设定价格执行 | 回测与实际执行偏差 |

### 3.5 两类策略的关联与互补

- 关联：两者都属于趋势跟踪，收益来源可能高度相关。
- 差异：双均线强调平滑后的方向变化；海龟强调价格突破与波动率风险尺度。
- 互补：不能仅把两者并列就称为分散化。多策略系统应加入低相关资产、不同时间尺度或不同收益来源，并设置组合层风险预算。

- 扩大样本与滚动检验：见附录A-02。
- 加入交易约束与成本压力测试：见附录A-03。
- 建立市场状态识别：见附录A-05。
- 研究多策略组合配置：见附录A-06。

本章个人思考落点：

- TASK3的价值不是证明MA5/MA15可以盈利，而是第一次把数据、信号、成本、基准和评价指标连成完整闭环。
- 双均线固定全仓进出后，风险大小仍取决于市场波动，说明“规则明确”不等于“风险已经标准化”。

## 第四章 机器学习在量化交易中的应用

### 4.1 机器学习研究流程

按课程PPT和前期实践归纳：

1. 明确预测对象和决策对象。
2. 检查数据质量、缺失值、异常值和时间边界。
3. 只在训练数据内完成标准化、筛选和参数选择。
4. 比较简单模型和复杂模型。
5. 使用与任务相匹配的指标评价。
6. 将预测概率或排序转化为仓位和交易信号。
7. 纳入成本、换手、回撤和样本外稳定性。

强调：

> 预测层回答“未来结果可能是什么”，决策层回答“是否交易以及持有多少”，执行层回答“订单能否按预期成交并受到怎样的风险约束”。三层不能用同一个模型分数代替。

### 4.2 TASK5：分类流程与外部有效性

TASK5的乳腺癌案例定位为机器学习流程教学，不作为金融市场证据。

可报告结果：

- 569例样本，455例训练、114例测试。
- 特征选择只读取训练集，最终保留6项变量。
- 逻辑回归和随机森林测试ROC-AUC约0.994，梯度提升约0.992，决策树约0.972。
- 多个模型区间高度重叠，不能按千分位差异确定稳定排名。

方法收获：

- 标签方向必须先统一。
- 数据划分应先于特征筛选。
- AUC、平衡准确率、召回率、F1和概率校准回答不同问题。
- 特征重要性解释的是模型依赖关系，不代表因果关系。

金融数据补充实验：

- 三种金融预测口径最高样本外AUC约为0.533、0.529和0.524。
- 置信区间均覆盖0.500，不把0.52修饰为有效交易信号。
- 60日截面排名中，逻辑回归AUC从2023年的0.752下降到2024年的0.575和2025年的0.509，说明关系可能随市场状态变化。
- 该失败结果说明随机划分的教学案例经验不能直接迁移到金融时间序列。

### 4.3 TASK6：横截面排序与组合构建

主任务设计：

- 使用股票—季度面板数据。
- 前7个季度训练、后3个季度测试；训练期内部使用扩展窗口验证。
- 比较线性回归、Ridge回归、逻辑回归、决策树、随机森林和梯度提升。
- 以季度Spearman秩相关系数（IC）评价预测排序。
- 若复杂模型的验证期平均IC相对简单模型优势不超过0.01，选择更简单模型。
- 最终选择线性回归构建季度前30名等权组合。
- 单边综合成本假设为20个基点，按单边换手率扣除。

核心结果：

| 项目 | 结果 | 报告解释 |
|---|---:|---|
| 线性回归验证期平均IC | 0.129 | 训练期内部具有有限排序信息 |
| 线性回归测试期平均IC | 0.273 | 3个测试季度均为正 |
| 线性回归前30名组合净累计收益 | 41.46% | 仅3个季度，属于短样本描述 |
| 同期全市场等权累计收益 | -15.91% | 作为同季度样本基准 |
| 随机森林前30名组合净累计收益 | 50.68% | 未按测试结果改选模型 |
| 线性模型平均单边换手率 | 83.33% | 成本和可交易性不可忽略 |

必须紧邻结果披露：

- 测试期只有3个季度。
- 3个季度均为正导致季度序列计算的最大回撤为0，不代表日度资产没有回撤。
- 年化收益率和夏普比率不作为TASK8的核心结论。
- 原始数据缺少财务指标实际披露日、历史指数成分、停牌、ST和流动性标记，可能存在时点可得性与幸存者偏差。
- 随机森林测试收益较高不构成看过测试集后重新选择模型的理由。

### 4.4 TASK6附加实验：预测改善不等于交易改善

可报告结果：

| 项目 | 结果 |
|---|---:|
| 3日方向静态逻辑回归验证AUC | 0.692 |
| 3日方向静态逻辑回归测试AUC | 0.520 |
| 180行滚动逻辑回归测试AUC | 0.571 |
| 机器学习择时累计收益 | 0.50% |
| 同期买入持有累计收益 | 9.93% |
| 同期均线策略累计收益 | 9.68% |

写作边界：

- 三轮调参反复观察了同一测试窗口，因此0.571属于探索性结果。
- AUC改善没有转化为更高累计收益。
- 原因可从阈值、持仓时间、市场暴露、交易次数、盈亏比和成本共同分析，不能只看分类准确率。

### 4.5 机器学习的优势与局限

优势：

- 能处理多个特征及非线性关系。
- 可以输出概率或排序，为动态仓位提供输入。
- 支持系统比较、交叉验证和自动化更新。

局限：

- 金融标签噪声高，关系会随市场状态变化。
- 多个价量特征可能信息同源。
- 参数和特征容易对验证窗口过拟合。
- 高AUC、高IC和高回测收益并非同一概念。
- 数据泄漏、幸存者偏差和反复查看测试集会使结果过于乐观。
- 复杂模型不必然优于简单模型，可解释性和稳定性同样重要。

正文引用改进建议：

- 时点可得数据治理：见附录A-01。
- 嵌套或滚动样本外验证：见附录A-04。
- 模型漂移监控与停用规则：见附录A-07。

### 4.6 机器学习部分的个人思考

这一节不单独抒情，而是用TASK5和TASK6的反差形成认识变化：

1. 乳腺癌数据中简单逻辑回归与复杂模型表现接近，说明当X与Y关系清晰时，复杂度不一定是主要矛盾。
2. 金融数据三种定义的AUC接近0.5，且模型管线通过随机标签与人工标签对照检查后，失败更可能来自目标、信息覆盖和时间稳定性，而不只是代码错误。
3. TASK6第一轮验证AUC为0.756、测试AUC为0.335，随后降低复杂度和缩短目标后，验证分数下降而测试排序改善；这使个人认识从追求验证集最高分转向保护独立测试和控制搜索范围。

### 5.3 JoinQuant长期平台回测：收益、回撤和暴露不可分开

| 策略 | 累计收益 | 年化收益 | 超额收益 | 最大回撤 | 夏普比率 | 市场敏感度 | 波动率 |

| B | 2.91% | 0.39% | -31.59% | -12.31% | -0.77 | 0.164 | 4.70% |
| C | 71.84% | 7.69% | 14.23% | -16.91% | 0.32 | 0.426 | 11.70% |

1. 策略A接近盈亏平衡却承受36.97%的最大回撤，说明简单高仓位择时没有在该样本中形成足够的风险补偿。

3. 策略C取得71.84%累计收益和14.23%累计超额，是三者中样本内收益—回撤配合较好的方案；但其相对基准最大回撤仍为30.37%，并且历史领先不能外推为未来盈利承诺。

## 第六章 多策略系统与综合风险分析

### 6.1 预测—决策—执行三层系统

计划绘制中文流程图：

1. 预测层：规则信号、突破信号、机器学习概率或排序。
2. 决策层：阈值、市场状态过滤、风险预算和目标仓位。
3. 执行层：订单检查、成本、成交、止损、监控和日志。

### 6.2 多策略组合思路

不直接把TASK3、TASK4和TASK6简单平均，而是按以下步骤构建：

1. 统一数据时点、成本和评价窗口。
2. 分别估计策略收益、波动、回撤、换手和相关性。
3. 识别共同趋势暴露，避免把高度相关策略误认为分散化。
4. 在组合层设置单策略风险预算、总仓位和回撤阈值。
5. 保留现金或低风险资产作为执行缓冲。
6. 使用滚动样本外数据决定是否启用、降权或停用策略。

### 6.3 四类风险分析

| 风险维度 | 报告内容 |
|---|---|
| 最大回撤 | 深度、持续时间、恢复时间和形成原因 |
| 市场环境 | 趋势、震荡、上涨、下跌和高波动环境 |
| 参数敏感性 | 邻近参数是否得到相似结果，是否依赖单一点值 |
| 压力测试 | 成本翻倍、单日急跌、连续下跌和流动性不足 |

另行补充：

- 数据风险：缺失、复权、披露日和成分股偏差。
- 模型风险：漂移、过拟合和指标错配。
- 执行风险：滑点、拒单、延迟和成交限制。
- 治理风险：没有版本冻结、日志或策略停用条件。

### 6.4 从单次模型到持续研究系统

结合Jump Trading课件，报告将把系统能力总结为：

- 预测期限、有效样本量、模型容量和执行速度需要共同设计。
- 静态回测不足以应对市场分布变化，应按时间和市场状态验证。
- 策略上线后需要监控信号衰减、输入分布、成本和成交偏差。
- 可复现数据、清晰文档、版本冻结和交接流程本身就是量化研究能力。
- 更好的量化系统不是一次得到最高收益，而是能够发现失效、解释失效并安全迭代。

本节个人思考落点是：专业量化能力不只表现为会写模型，还表现为是否愿意保留负结果、接受不确定性、让研究可以被自己和他人重新检查。用户提出的哲学问题在此转化为技术纪律：金融市场不保证存在稳定、可发现且扣除成本后仍可盈利的信号，因此研究过程必须允许假设被否证，并把“没有发现可重复增量信息”视为可报告结果。

## 第七章 结论与展望

### 7.1 主要学习收获

按课程PPT的四类能力总结：

1. 系统思维：能够把量化交易理解为数据、模型、策略、执行和风控共同组成的系统工程。
2. 数据思维：能够检查数据口径，并用可复算证据支持或否定交易假设。
3. 风险意识：认识到评价目标取决于角色；机构场景可在治理约束内更进取地追求收益和可解释性，个人投资场景则更强调稳定、回撤和可持续执行。
4. 实践能力：完成数据管线、指标计算、规则回测、机器学习建模和组合评价。

结论不能只按能力清单陈述，还要写出认识变化：

- 从关注收益结果转向同时关注证据质量和风险来源。
- 从寻找单一最优参数转向观察参数邻域和样本外稳定性。
- 从认为模型越复杂越强转向先定义问题、数据和验证纪律。
- 从把回测视为终点转向把监控、执行和复盘视为研究的一部分。
- 从默认“市场中一定存在可发现的盈利信号”转向把信号存在本身视为需要证据支持、允许被否证的研究假设。

### 7.2 核心结论

- 规则策略的主要价值是透明和可检验；在当前样本中改善了相对风险，但没有实现正绝对收益。
- 机器学习扩大了特征和模型空间，也放大了数据泄漏、过拟合和测试集污染风险。
- 高模型分数只有通过交易决策、成本和样本外表现检验后才具有量化交易意义。
- 现阶段最可靠的成果是研究方法和风险纪律，而不是对未来收益的承诺。
- TASK7已经完成从规则、统一历史回测到私有模拟盘部署的系统化推进，但尚无模拟盘运行数据，不能把部署完成等同于执行有效。

### 7.3 未来计划

按优先顺序而非技术炫技展开：

1. 持续积累TASK7模拟盘净值、订单、持仓、成本和执行偏差，先验证系统是否按冻结规则运行。
2. 深入策略研究，扩展跨标的、跨周期和跨市场状态的样本外验证，并加强金融机制解释。
3. 在严格时间戳和简单基准下研究深度学习、多模态模型与非结构化数据，重点探索领域专用化模型能否提供价格量特征之外的增量信息。
4. 完善时点可得数据、历史成分、流动性过滤和模型输入漂移监控。
5. 建立模型与策略的降权、停用和重新训练规则；证据充分后再研究多策略风险配置和小资金验证。

深度学习方向要写成“下一阶段研究问题”，而不是未来必然更优的技术路线。优先回答三个问题：非结构化数据是否在决策时真实可得；相对简单模型是否带来稳定增量；增量能否在成本、延迟和风险约束后转化为交易价值。

### 7.3 图表规则

- 图和表分别全文连续编号。
- 所有标题、图例、坐标轴和变量名使用中文。
- 同一指标使用相同小数位。
- 每幅图表前后必须有解释段落，依次说明结论、读法和限制。
- 不使用软件截图或直接复制旧报告页面。
- 表格不跨页，列标题尽量不折行。
- 图表在100%显示比例下清晰可辨。
- 颜色含义统一：策略主线使用深蓝，比较策略使用橙色，基准使用灰色；风险或回撤使用克制的红色。
- 图题使用中性描述，结论放在相邻正文；副标题注明时间、样本、单位、成本或基准。
- 不能只依靠颜色区分系列，同时使用线型、标记、明暗或直接标签。
- 普通绝对量柱形图从零开始；正负收益比较必须保留清晰零线和正负号。
- 同类图采用一致坐标尺度；若必须截断坐标，应在副标题或图注明确说明。

### 7.4 图表技术分析协议

每幅定量图表必须在正文完成以下五层分析：

1. **构造说明：** 数据来源、样本区间、标的、频率、指标定义、成本和基准。
2. **图形读取：** 说明横纵轴、系列、零线或随机基准线，以及读者应观察的变化。
3. **技术结论：** 给出方向、幅度、持续性、相对差异或参数邻域，而不只复述图题。
4. **稳健性与限制：** 说明样本量、市场状态、置信区间、参数敏感性、重叠窗口或缺失数据如何影响判断。
5. **个人解释：** 说明这张图改变了什么认识，以及后续分析或行动如何调整。

不同图形的专门要求：

- **资产曲线：** 必须与基准和回撤一起解释；不能只看期末高低，需说明市场暴露、空仓时间和成本。
- **回撤曲线：** 分析深度、持续时间和恢复情况；较低回撤若来自长期持有现金，需要单独说明。
- **参数热力图：** 观察较优区域是否连续，不只圈出最大值；孤立极值优先视为过拟合风险。
- **AUC图：** 显示0.500随机基准线；有区间时必须呈现区间，没有区间时说明独立时间状态数量。
- **IC图：** 显示零线并区分平均值、最低值和正IC季度比例。
- **季度收益图：** TASK6只有3个测试季度，使用分组柱形图和精确表格，不绘制容易造成长期趋势错觉的平滑曲线。
- **验证与测试对照：** 强调参数选择发生在何时，避免把看过测试结果后的方案称为独立样本外结果。
- **TASK7净值与回撤图：** 明确是本地扩展样本复算，分析策略C优势主要形成于何时、策略A回撤持续多久，以及策略B低回撤与低平均仓位的关系；平台指标另表披露，不能把两套口径拼成同一条曲线。
- **TASK7成本压力图：** 三策略使用相同纵轴和清晰零线，基础成本与双倍成本采用填充/空心或明暗区分；同时报告百分点变化，不能只说“仍盈利”或“更稳健”。
- **TASK7短窗结果：** 三策略收益均为0时不绘图；用表格说明5个交易日、0/0交易、空仓、基准2.65%和机会成本。
- **流程图：** 只用于解释预测、决策、执行和监控关系，不作为结果证据。

个人思考不能脱离图表单独出现。例如，不写“我认识到风险很重要”，而写“图3显示两项策略绝对收益均为负，但海龟策略回撤更低；这使我把评价重点从是否押对方向转向错误发生时损失是否受控”。

## 八、指标与格式统一口径

### 8.1 数值格式

| 指标 | 保留位数 |
|---|---|
| 收益率、回撤、波动率、胜率、换手率 | 2位小数 |
| 夏普比率 | 2位小数 |
| AUC、IC、F1等模型指标 | 3位小数 |
| 交易次数、样本数、季度数 | 整数 |
| 金额 | 元或万元，全文统一 |

负值使用半角负号，如`-5.67%`。正文避免同一指标一处写小数、一处写百分数。

### 8.2 指标定义

- 累计收益率：期末资产相对期初资产的总变化。
- 年化收益率：将样本收益折算为一年；样本过短时仅作描述，不作为核心结论。
- 最大回撤：资产相对历史高点的最大跌幅。
- 夏普比率：单位波动对应的超额收益；负收益或极短样本中解释价值有限。
- AUC：随机抽取一组正负样本时，模型把正样本评分排在负样本之前的概率。
- 秩相关系数（IC）：预测排名与实际收益排名之间的Spearman相关。
- 换手率：组合持仓调整的比例；必须说明单边或双边口径。

## 九、附录A：基于前期作业复盘的改进建议

附录建议逐项编号，并在正文对应位置引用。

### A-01 建立时点可得的数据治理

记录数据源、下载时间、复权方式、财务指标披露日、历史成分股及字段版本，降低未来信息和幸存者偏差。

### A-02 扩展标的、周期和滚动样本外检验

将TASK3和TASK4从单只股票、约13个月样本扩展到多标的、多市场状态，并按滚动窗口冻结参数后检验。

### A-03 加入可交易性和成本压力测试

统一纳入手续费、印花税、滑点、最低佣金、整数手、停牌、涨跌停和成交失败，并测试成本翻倍情景。

### A-04 使用更严格的机器学习验证

采用时间顺序划分、purge间隔、滚动样本外或嵌套验证；测试集只在模型和参数冻结后查看一次。

### A-05 建立市场状态识别

用趋势、波动和流动性指标划分市场环境，验证策略在不同状态下的表现；状态阈值必须在训练或验证期确定。

### A-06 构建组合层风险预算

在统一口径下测量策略相关性、市场暴露和回撤贡献，设置单策略权重上限、总仓位、现金缓冲和组合回撤阈值。

### A-07 建立模型监控和停用规则

监控AUC、IC、收益、换手、滑点和数据新鲜度；当预测能力或执行质量持续恶化时降权、暂停或重新训练。

### A-08 持续积累TASK7模拟交易证据链

保存策略版本、信号、订单、成交、成本、持仓、异常和净值记录；明确区分历史回测、影子跟踪、模拟交易与真实资金交易。前20个交易日先核验规则和执行一致性，约3个月后再比较收益、回撤、平均仓位和成本，至少6个月后才讨论稳定性。
