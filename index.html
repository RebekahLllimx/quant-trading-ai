Quantitative Trading ResearchCourse Portfolio

About this project

Eight course projects from the Peking University Guanghua Business Analytics Workshop. The portfolio develops from market-data engineering and technical indicators to rule-based backtests, machine-learning experiments, and strategy monitoring. Each dashboard is a self-contained HTML artifact that can be inspected without a backend. Results are educational research outputs, not live trading records or investment advice.

Task 1
Market Data Engine
Prepare adjusted A-share and Hong Kong equity data, then explore candlesticks, returns, and cross-market comparisons in a portable dashboard.
Open dashboard
Task 2
Technical Indicators
Implement and compare eight indicator families, including RSI, MACD, Bollinger Bands, ATR, KDJ, moving averages, CCI, and ADX.
Open dashboard
Task 3
Moving-Average Strategy
Backtest a long-only crossover rule with explicit execution timing, transaction costs, benchmark comparison, and parameter sensitivity.
Open dashboard
Task 4
Turtle Trading Strategy
Evaluate breakout entries, ATR-based exits, volatility-scaled positions, pyramiding, and sensitivity to market regime.
Open dashboard
Task 5
Machine-Learning Cases
Build a validated classification workflow on a teaching dataset, then document why analogous financial classification experiments remained weak.
Open dashboard
Task 6
ML Strategy Research
Use chronological validation, cross-sectional ranking, turnover-aware portfolio construction, and guarded time-series experiments.
Open dashboard
Task 7
Strategy Monitoring
Compare three frozen strategies across platform backtests, local research, and a separate public-data shadow portfolio.
Open dashboard
Task 8
Synthesis Report
Connect the data, indicator, backtest, modeling, and monitoring work while stating the evidence limits of each result.
