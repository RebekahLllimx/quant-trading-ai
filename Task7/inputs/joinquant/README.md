# JoinQuant脱敏证据与导出区

此目录接收用户从JoinQuant手工提供的脱敏回测证据和模拟盘数据。

`backtest_summary.json`记录三次已完成平台回测的结构化指标、证据文件名，
以及三个私有模拟盘“已部署、等待数据”的状态。它不包含账号或访问方式。

允许字段：

- 日期
- 策略代号（A/B/C）
- 证券代码
- 方向
- 委托数量与成交数量
- 委托价与成交价
- 交易费用
- 持仓市值、现金、总资产
- 平台状态或拒单原因

禁止内容：

- 账号、密码、验证码
- Cookie、Token或浏览器会话
- 手机号、邮箱或身份证明
- 私有分享链接
- 与课程验证无关的个人资产信息

在模拟盘已经部署但没有平台运行数据时，Dashboard使用
`deployed_waiting_data`状态；不能用影子结果填充“实际模拟”收益字段。
