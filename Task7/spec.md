# TASK7 实施规格（已确认）

## 一、任务定位

TASK7不把短期模拟收益作为策略有效性的证明，而是完成一次可以持续观察的部署实验。实验从JoinQuant平台模板出发，分别保留平台基线、加入自主风险控制、参考社区形成第三种策略，并在相同资金、成本和时间边界下运行三个模拟盘。由于课程提交时模拟盘尚未经历足够交易日，正式报告区分历史回测、自动影子跟踪与JoinQuant模拟交易三类结果，不用影子净值替代平台实际成交结果。

## 二、研究问题

1. JoinQuant模板策略在加入交易成本、滑点和订单约束后，历史结果发生多大变化？
2. ATR风险预算与仓位上限能否减少最大回撤和单一市场暴露？
3. 社区常见的宽基ETF动量轮动，在统一成本、T−1信息和冻结标的池后是否仍有稳定性？
4. 三种策略的收益差异来自信号质量、平均仓位、换手、市场方向暴露还是实际成交偏差？
5. 自动影子跟踪与JoinQuant模拟盘的信号、订单和净值为什么会出现差异？

## 三、三个部署策略

### 3.1 策略A：平台模板基线

- 目的：保留JoinQuant模板的最低复杂度版本，作为后续修改的可解释基准。
- 标的：沪深300ETF `510300.XSHG`。
- 信号：使用截至T−1日的收盘价与20日简单移动平均线。收盘价高于MA20时目标仓位100%，低于MA20时空仓。
- 执行：交易日9:35检查一次，按平台实际可成交价格下单。
- 风控：不额外设置ATR止损，只保留停牌、涨跌停、订单状态和整数手检查。
- 研究价值：暴露全仓模板在震荡、跳空和高波动阶段的风险，不能作为推荐实盘方案。

### 3.2 策略B：双均线与ATR风控

- 目的：承接TASK3的双均线信号与TASK4的ATR风险管理，是本次自主设计的主策略。
- 标的：沪深300ETF `510300.XSHG`。
- 信号：使用T−1日数据，MA10高于MA30时允许持仓，MA10不高于MA30时空仓。
- 波动率：使用20日平均真实波幅ATR。
- 止损：持仓价格跌破只上移不下移的2倍ATR止损线时退出。
- 仓位：单次止损预算不超过账户权益的1%，目标仓位不超过50%，不使用杠杆和金字塔加仓。
- 账户保护：策略自身净值从部署后高点回撤达到5%时暂停新开仓5个交易日。
- 参数对照：MA5/20、MA10/30、MA20/60三组只在开发期与验证期比较，最终方案不根据2026年样本外结果反复修改。

### 3.3 策略C：社区启发的宽基ETF动量轮动

- 目的：吸收聚宽社区中宽基ETF轮动、低换手和空仓避险的思想，同时删除难以解释的多因子择时和事后挑选参数。
- 冻结ETF池：
  - 沪深300ETF `510300.XSHG`
  - 中证500ETF `510500.XSHG`
  - 创业板ETF `159915.XSHE`
- 调仓频率：每周三10:00检查一次，降低日频轮动产生的换手和噪声。
- 动量：使用截至T−1日最近15个交易日的对数价格回归斜率年化后乘以拟合优度R²。只选择得分最高且得分大于0的ETF。15日窗口由开发期与验证期的15/20/30日邻域检验选出；2026年样本外结果不参与选择。
- 仓位：目标仓位50%，剩余资金保留现金；所有ETF得分不大于0时全部空仓。
- 约束：不加入回测开始后才上市的行业或主题ETF，不根据最终测试期收益更换ETF池。
- 社区参考：
  - 聚宽社区《宽基ETF动量轮动钝化RSRS择时-回撤小》提供510300、510500与159915宽基池及空仓思路。
  - 聚宽社区《ETF核心资产轮动-非每日轮动》提供周度轮动与较高滑点检验的思路。
  - 社区代码只作为研究线索，正式代码重新实现并单独执行未来信息、成本与可交易性检查。

## 四、统一回测口径

实际平台回测已统一设置为2019-01-01至2026-07-23、初始资金500,000元、日频和沪深300基准。本地研究仍保留2016-2026的开发、验证和参数冻结分段，用于稳健性与自动影子跟踪；两套窗口在报告中分开披露。

### 4.1 时间划分

- 开发期：2016-01-01至2023-12-31。
- 验证期：2024-01-01至2025-12-31。
- 最终样本外期：2026-01-01至模拟盘创建日前一交易日。
- 模拟期：以JoinQuant实际创建日期为起点，持续更新。

若平台数据权限或ETF上市日期影响时间范围，三个策略使用共同可得的最晚起始日，不能让某一策略单独使用更有利的历史窗口。

### 4.2 资金与交易规则

- 每个策略初始资金500,000元，三个模拟盘彼此独立。
- 基准统一使用沪深300指数 `000300.XSHG`。
- 使用平台ETF佣金规则、最低佣金与滑点设置，并增加成本翻倍压力测试。
- 所有信号只使用决策时点已经完成的数据。
- 下单前检查停牌、涨跌停、当前价格、目标数量和100股整数手。
- 下单后检查订单是否成交、部分成交、撤单或拒绝，并写入日志。
- 不允许融资、融券、做空或外部人工覆盖策略订单。

### 4.3 参数选择

参数选择不以单一窗口累计收益最大为目标。开发期先排除存在未来信息、交易次数过少或成本异常的方案；验证期综合比较最大回撤、夏普比率、年化波动率、换手率和年度方向稳定性。最终样本外期只在参数冻结后查看一次。社区文章中的参数必须进入邻域敏感性检查，不能因文章标题或作者回测结果直接采用。

## 五、评价指标与风险暴露

### 5.1 结果指标

- 累计收益与相对基准超额收益
- 年化波动率
- 夏普比率
- 最大回撤与回撤持续时间
- 日胜率和完整交易胜率
- 交易次数、单边换手率、成交成本与滑点

### 5.2 暴露指标

- 平均、最高和最新股票市场仓位
- 现金比例与空仓天数
- 单一ETF集中度
- 相对沪深300的Beta和相关性
- 隔夜持仓比例
- 不同市场状态下的收益、波动和回撤
- 成本翻倍后的收益变化
- 订单未成交、部分成交、停牌和涨跌停事件数

### 5.3 公平比较

策略A的仓位上限高于策略B和C，因此报告同时给出原始净值结果和按平均市场暴露解释的结果。低回撤如果主要来自长期持有现金，不能直接解释为信号更准确。策略C拥有跨ETF选择能力，报告将其分散化和资产选择收益与择时收益分开讨论。

## 六、自动更新Dashboard

### 6.1 页面定位

Dashboard是持续实验记录页，不是实时券商交易终端。默认页先回答三个问题：三个策略当前是什么状态、净值和风险如何变化、网页数据更新到哪一天。公开页面不提供JoinQuant模拟盘链接、密码、账号信息或任何登录凭证，只展示脱敏后的策略名称、运行状态和研究结果。

### 6.2 数据层级

1. **JoinQuant模拟盘**：平台产生的真实模拟订单、成交、持仓和净值，是评价实际模拟表现的唯一主来源。
2. **自动影子跟踪**：GitHub Actions在每个交易日收盘后获取公开行情，以冻结规则重新计算三个策略，用于保持网页连续更新。
3. **历史回测**：参数冻结前完成的开发、验证与最终样本外结果，只作为部署基线。

Dashboard必须给每个数字标明数据层级，自动影子跟踪不得命名为“聚宽实盘收益”或“模拟盘实际收益”。

### 6.3 更新链路

项目已有工作流在工作日北京时间18:00更新市场数据。TASK7扩展沿用同一架构：

1. 获取510300、510500、159915和000300的最新日线行情。
2. 验证交易日、重复日期、缺失值、复权口径和最新完整日期。
3. 用冻结策略代码更新三个影子组合的信号、持仓、订单和净值。
4. 写入轻量JSON/CSV数据文件和数据更新时间。
5. GitHub Pages自动展示最新数据，无需每天重新生成报告。
6. 如果取得JoinQuant导出的模拟交易数据，将其导入独立的`actual`数据集，与影子结果并排展示。

JoinQuant目前提供带密码的模拟交易分享链接，但未找到面向个人模拟盘的稳定公开取数API。第一版不自动抓取需要密码的页面，也不在GitHub中保存账号、密码、Cookie或私有分享链接。模拟盘实际数据先采用平台截图和定期导出；只有在确认官方允许且接口稳定后，才单独评估私有同步方式。

### 6.4 页面结构

- 顶部：最新完整交易日、最近更新时间、数据来源状态和JoinQuant运行状态。
- 策略总览：三张策略卡片，显示当前信号、持仓ETF、仓位、累计收益、最大回撤和数据层级。
- 净值比较：三个影子策略、沪深300基准；有模拟数据后增加JoinQuant实际净值。
- 风险比较：回撤曲线、滚动波动率、市场仓位和现金比例。
- 执行比较：目标订单与实际成交、滑点、交易成本、拒单和部分成交。
- 参数与版本：策略版本、参数、创建日期、最后一次代码变更和脱敏运行状态。
- 日志表：按日期列出信号、订单、成交、持仓、异常和备注。
- 方法与边界：解释影子跟踪、模拟交易和真实券商实盘的区别。
