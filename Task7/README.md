## 三个策略

1. **A · 平台模板基线**：`510300.XSHG`，T−1收盘价高于MA20时目标仓位100%，否则空仓。
2. **B · 双均线 + ATR风控**：`510300.XSHG`，MA10/30趋势过滤、ATR20、2倍ATR移动止损、1%风险预算、50%仓位上限、5%账户回撤暂停。
3. **C · 宽基ETF动量轮动**：`510300.XSHG`、`510500.XSHG`、`159915.XSHE`，每周三用15日对数价格斜率×R²打分，持有最高正分ETF的50%，否则现金。15日由开发期与验证期的15/20/30日邻域检验选出。

## JoinQuant统一设置

- JoinQuant平台回测区间：2019-01-01至2026-07-23
- 本地研究/影子区间：2016-01-01至2026-07-24
- 初始资金：每个策略500,000元
- 基准：`000300.XSHG`
- 频率：日频
- 复权：平台真实价格模式
- 成本：ETF佣金3bp、最低5元、无印花税
- 滑点：比例滑点10bp
- 未来信息：启用`set_option("avoid_future_data", True)`

平台实际结果与本地结果可能因数据源复权、开盘成交模型、订单撮合和涨跌停处理不同而不一致。差异本身是报告需要分析的结果，不应通过改参数强行消除。
