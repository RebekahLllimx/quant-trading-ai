# Task 6 Dashboard

- `index.html` is the read-only offline research dashboard.
- `artifact.json` is the structured presentation contract generated by `scripts/build_dashboard.py`.
- `tools/csv_regression.html` is an isolated browser-only teaching tool for fitting simple linear or logistic models to a user-selected CSV.

The CSV tool keeps data in browser memory and has no backend or database. Its downloaded JSON model is not interchangeable with the scikit-learn model bundles generated by the Python pipeline.

Rebuild the dashboard from the repository root:

```bash
python Task6/scripts/build_dashboard.py
python Task6/scripts/validate_results.py
```
